# Publishing HSA to HuggingFace Hub

This guide explains how to prepare and upload trained HSA models to HuggingFace Hub.

## Prerequisites

1. Install dependencies:
```bash
pip install transformers huggingface-hub
```

2. Login to HuggingFace:
```bash
huggingface-cli login
```

## Saving a Trained Model

After training, save your model in HuggingFace format:

```python
from hsa import HSAConfig, HSAForCausalLM
import torch

# Load your trained model checkpoint
checkpoint_path = "/path/to/checkpoint/pytorch_model.bin"
config_path = "/path/to/hsa/configuration_hsa.py"

# Initialize config with training settings
config = HSAConfig(
    vocab_size=32000,  # From tokenizer
    hidden_size=2048,
    intermediate_size=8192,
    num_hidden_layers=24,
    num_attention_heads=16,
    num_key_value_heads=16,
    window_size=128,
    tree_slots=8,
    max_position_embeddings=8192,  # Training max seq_len
    # FAST Config B settings
    mtp_horizons=2,
    mtp_position_fraction=0.5,
    latent_position_fraction=0.2,
    thought_fraction=0.03,
    thought_dim=256,
    w_mtp=0.35,
    w_latent=0.25,
    w_variance=0.45,
)

# Initialize model
model = HSAForCausalLM(config)

# Load weights
state_dict = torch.load(checkpoint_path, map_location="cpu")
model.load_state_dict(state_dict)

# Save to HuggingFace format
output_dir = "./hsa-trained"
model.save_pretrained(output_dir)

print(f"Model saved to {output_dir}")
```

## Repository Structure

Your uploaded repo should contain:

```
your-org/hsa-trained/
├── README.md                    # Model card (copy from hsa/README.md)
├── config.json                  # Auto-generated by save_pretrained()
├── generation_config.json       # Provided in hsa/
├── pytorch_model.bin            # Model weights
├── tokenizer/
│   ├── tokenizer.json
│   ├── tokenizer_config.json
│   └── special_tokens_map.json
├── .gitattributes
└── model_index.json (optional)
```

## Uploading to HuggingFace Hub

### Method 1: Using `push_to_hub()` (Recommended)

```python
# After saving locally
model.push_to_hub("your-username/hsa-trained")
tokenizer.push_to_hub("your-username/hsa-trained")
```

### Method 2: Using Git

```bash
# Clone your HuggingFace repo
git clone https://huggingface.co/your-username/hsa-trained
cd hsa-trained

# Copy model files
cp -r /path/to/saved/model/* .
cp -r /path/to/hsa/tokenizer/* .

# Upload
git add .
git commit -m "Add HSA trained model"
git push
```

## Creating the Model Card

1. Edit the README.md with your model-specific details:
   - Training data source and size
   - Model parameters and sizes
   - Performance metrics on your evaluation set
   - Intended use cases
   - Known limitations

2. Add metadata at the top:

```yaml
---
language: en
license: apache-2.0
library_name: transformers
tags:
  - causal-lm
  - hierarchical-attention
  - long-context
datasets:
  - dolma
model_index:
- name: hsa-lm
  results: []
---
```

## Loading from HuggingFace Hub

After uploading, anyone can load your model:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("your-username/hsa-trained")
tokenizer = AutoTokenizer.from_pretrained("your-username/hsa-trained")

# Generate text
inputs = tokenizer("The quick brown fox", return_tensors="pt")
outputs = model.generate(**inputs, max_length=100)
print(tokenizer.decode(outputs[0]))
```

## Troubleshooting

**Q: File too large?**
A: Use HuggingFace's Git LFS (Large File Storage). It's automatically enabled for `.bin` files.

**Q: Config.json not generated?**
A: Make sure HSAConfig is properly registered. Run:
```python
from transformers import AutoConfig
AutoConfig.from_pretrained("your-username/hsa-trained")
```

**Q: Import errors when loading?**
A: Ensure transformers is up-to-date and HSA is installed:
```bash
pip install -U transformers
pip install -e /path/to/hsa-transformers
```
